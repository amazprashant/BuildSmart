What is an API?

API (Application Programming Interface) is a set of rules that lets two applications communicate. One app makes a request; the other returns a response. APIs are the glue of the modern web.

Real-world analogy

A waiter at a restaurant is an API. You (client) place an order → the waiter (API) takes it to the kitchen (server) → brings back your food (response). You never interact with the kitchen directly.

📱

Mobile App

Calls weather API to show forecasts. No need to build its own weather system.

💳

Payment

Stripe API handles billing — your app just calls the API with card details.

🗺

Maps

Google Maps API provides mapping. Embed a map with 5 lines of code.

🤖

AI/ML

OpenAI API gives you GPT-4 without training your own LLM.

REST — Architectural Style for APIs

REST (Representational State Transfer) is a set of conventions for building web APIs. It uses HTTP methods and URLs to represent operations on resources.

REST Resources & Methods
GET /users
→
List all users
GET /users/42
→
Get user #42
POST /users
→
Create new user
PUT /users/42
→
Replace user #42
DELETE /users/42
→
Delete user #42
6 REST Constraints

1. Client-Server — UI and data storage are separated.
2. Stateless — Each request contains all info needed; no server-side session.
3. Cacheable — Responses can be cached for performance.
4. Uniform Interface — Consistent URL naming and HTTP methods.
5. Layered System — Client doesn't know if it talks to origin server or cache/proxy.
6. Code on Demand — Optional: server can send executable code.

JSON — The Data Format

Web APIs exchange data in JSON (JavaScript Object Notation). It's lightweight, human-readable, and supported by every programming language.

# JSON response from a user API
{
  "id": 42,
  "name": "Alice Sharma",
  "email": "alice@example.com",
  "is_active": true,
  "scores": [95, 87, 92],
  "address": {
    "city": "Mumbai",
    "country": "India"
  }
}

# Supported types
string  → "hello"
number  → 42, 3.14
boolean → true, false
null    → null
array   → [1, 2, 3]
object  → {"key": "value"}
Why FastAPI loves JSON

FastAPI automatically converts Python dicts and Pydantic models to JSON responses — and parses incoming JSON into Python objects. Zero manual json.dumps() / json.loads() required.
