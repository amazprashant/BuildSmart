HTTP Methods Overview

MethodActionBody?Idempotent?Use Case
GETReadNo✅ YesFetch a resource
POSTCreateYes❌ NoCreate a new resource
PUTReplaceYes✅ YesReplace entire resource
PATCHUpdateYes❌ NoPartial update
DELETEDeleteNo✅ YesRemove a resource
Idempotent means

Calling the same request multiple times produces the same result. GET /users/1 always returns user 1. DELETE /users/1 always results in user 1 not existing. POST /users creates a new user each time — not idempotent.

All Methods in FastAPI

GETRead — Fetch data from server
@app.get("/items")
def get_items():
    return [{"id": 1, "name": "Laptop"}, {"id": 2, "name": "Phone"}]

@app.get("/items/{item_id}")
def get_item(item_id: int):
    return {"id": item_id, "name": "Laptop"}
POSTCreate — Send data to create a resource
from pydantic import BaseModel

class Item(BaseModel):
    name: str
    price: float

@app.post("/items", status_code=201)
def create_item(item: Item):
    # item is automatically parsed from request body
    return {"created": item}
PUTReplace — Replace entire resource
@app.put("/items/{item_id}")
def update_item(item_id: int, item: Item):
    return {"id": item_id, "updated": item}

# PUT replaces ALL fields — any missing fields get default/null values
PATCHPartial Update — Modify specific fields only
class ItemUpdate(BaseModel):
    name: str | None = None   # all fields optional
    price: float | None = None

@app.patch("/items/{item_id}")
def partial_update(item_id: int, update: ItemUpdate):
    return {"id": item_id, "patch": update.model_dump(exclude_unset=True)}
DELETEDelete — Remove a resource
@app.delete("/items/{item_id}", status_code=204)
def delete_item(item_id: int):
    # 204 No Content — successful delete returns no body
    return None

Complete CRUD Example

from fastapi import FastAPI, HTTPException
from pydantic import BaseModel
from typing import Dict

app = FastAPI()

class Item(BaseModel):
    name: str
    price: float
    in_stock: bool = True

# In-memory store (use a DB in production)
items: Dict[int, Item] = {}
next_id = 1

@app.get("/items")
def list_items():
    return items

@app.get("/items/{item_id}")
def get_item(item_id: int):
    if item_id not in items:
        raise HTTPException(status_code=404, detail="Item not found")
    return items[item_id]

@app.post("/items", status_code=201)
def create_item(item: Item):
    global next_id
    items[next_id] = item
    next_id += 1
    return {"id": next_id - 1, **item.model_dump()}

@app.put("/items/{item_id}")
def replace_item(item_id: int, item: Item):
    if item_id not in items:
        raise HTTPException(status_code=404, detail="Item not found")
    items[item_id] = item
    return item

@app.delete("/items/{item_id}", status_code=204)
def delete_item(item_id: int):
    if item_id not in items:
        raise HTTPException(status_code=404, detail="Item not found")
    del items[item_id]
HTTPException

FastAPI's HTTPException stops execution and returns an error response with the given status code and detail message. Use it to handle not-found, unauthorized, and other error cases cleanly.
