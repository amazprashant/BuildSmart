Production Best Practices

🏗

Project Structure

Use APIRouter to split routes by domain. Keep main.py lean — just app creation and router registration.

🔐

Authentication

Add JWT auth with python-jose and passlib. Use OAuth2 with Password flow for /docs compatibility. Never store passwords in plain text.

🗄

Database

Use SQLAlchemy with async sessions. Inject DB sessions as dependencies. Use Alembic for schema migrations — never alter tables manually.

📝

Logging

Use Python's logging module, structured JSON logs, and unique request IDs via middleware for traceability in production.

✅

Testing

Use pytest + httpx.AsyncClient with FastAPI's TestClient. Test each endpoint with valid input, invalid input, and edge cases.

📊

Monitoring

Add /health and /ready endpoints. Use Prometheus + Grafana or AWS CloudWatch for metrics and alerting.

Complete API Structure Template

my-fastapi-project/
├── app/
│   ├── main.py            # app creation, lifespan, router registration
│   ├── config.py          # settings from env vars (pydantic-settings)
│   ├── database.py        # DB engine, session, Base
│   ├── models/            # SQLAlchemy ORM models
│   │   └── user.py
│   ├── schemas/           # Pydantic request/response models
│   │   └── user.py
│   ├── routers/           # APIRouter per domain
│   │   ├── users.py
│   │   └── items.py
│   ├── services/          # business logic (not in routes)
│   │   └── user_service.py
│   └── dependencies.py    # shared Depends() functions
├── tests/
│   └── test_users.py
├── Dockerfile
├── docker-compose.yml
└── requirements.txt

What to Learn Next

⚡ Async SQLAlchemy

Full async database operations with SQLAlchemy 2.0 and asyncpg — 3–5× faster than sync.

🔐 JWT Auth

Implement login, access tokens, refresh tokens, and role-based access control.

🔄 WebSockets

FastAPI has built-in WebSocket support for real-time features like chat and live updates.

🧪 Testing

pytest + HTTPX AsyncClient for async test coverage. Mock dependencies. Test DB with SQLite in-memory.

📦 Celery / ARQ

Distributed task queues for reliable background jobs with retries, scheduling, and monitoring.

🐳 Kubernetes

Scale beyond a single container — orchestrate multiple pods, rolling deploys, and auto-scaling.

Build something real

The best next step is to build a real project: a REST API for a hobby app, an ML inference service, or a clone of a simple product. You'll encounter real problems that solidify everything you've learned in this course.
