What is FastAPI?

FastAPI is a modern, fast, Python web framework for building APIs. Created by Sebastián Ramírez in 2018, it's built on Starlette (web) and Pydantic (data validation) with Python type hints at its core.

FastAPI in one sentence

FastAPI gives you the speed of Node.js, the automatic validation of Pydantic, and auto-generated OpenAPI docs — all from Python type hints you'd write anyway.

⚡

Fast Performance

On par with NodeJS and Go. One of the fastest Python frameworks available.

🔍

Auto Validation

Pydantic validates all request data automatically. No manual checks needed.

📖

Auto Docs

Swagger UI + ReDoc generated automatically from your code. Zero config.

🔒

Type Safety

Python type hints catch bugs at development time, not at runtime.

Hello World in FastAPI

pip install fastapi uvicorn
# main.py
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def read_root():
    return {"message": "Hello, FastAPI!"}

@app.get("/users/{user_id}")
def get_user(user_id: int, include_details: bool = False):
    return {"user_id": user_id, "include_details": include_details}

# Run the server
# uvicorn main:app --reload

Visit http://localhost:8000/docs — Swagger UI appears automatically. Visit /redoc for ReDoc. No extra setup.

You write code once, docs are always up to date

FastAPI reads your function signatures, Pydantic models, and path decorators to build the OpenAPI schema. Your documentation is never out of sync with the actual API — it's generated from the code itself.
