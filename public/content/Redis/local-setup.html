Installation

Linux (Ubuntu/Debian)

sudo apt update
sudo apt install redis-server -y
sudo systemctl enable redis-server
sudo systemctl start redis-server

# Verify
redis-cli ping   # → PONG

macOS (Homebrew)

brew install redis
brew services start redis

# Verify
redis-cli ping   # → PONG

Windows (via Docker — recommended)

docker pull redis
docker run --name my-redis -p 6379:6379 -d redis

# Connect
docker exec -it my-redis redis-cli ping   # → PONG

Using Docker Compose

# docker-compose.yml
version: '3.8'
services:
  redis:
    image: redis:7-alpine
    ports:
      - "6379:6379"
    volumes:
      - redis_data:/data
    command: redis-server --appendonly yes

volumes:
  redis_data:

Connect with redis-cli

# Connect to local Redis
redis-cli

# Connect to remote Redis
redis-cli -h hostname -p 6379 -a your_password

# Run a single command without entering interactive mode
redis-cli GET mykey

# Ping to check connection
redis-cli ping
# → PONG
Tip:

In interactive mode, type help @string, help @hash, etc. to see commands by data type.

Essential CLI Commands for Setup

# Server info
INFO server
INFO memory
INFO stats

# Check configuration
CONFIG GET maxmemory
CONFIG GET bind
CONFIG GET requirepass

# Set password at runtime
CONFIG SET requirepass "yourpassword"
AUTH yourpassword

# List all keys (use carefully in production)
KEYS *
KEYS user:*       # pattern matching

# Flush data (careful!)
FLUSHDB           # flush current database
FLUSHALL          # flush ALL databases

# Select database (0-15)
SELECT 1          # switch to DB 1

Configuration File (redis.conf)

The config file is usually at /etc/redis/redis.conf (Linux) or /usr/local/etc/redis.conf (macOS).

# Key settings for development
bind 127.0.0.1          # only allow local connections
port 6379               # default port

# Set max memory (optional for dev)
maxmemory 256mb
maxmemory-policy allkeys-lru

# Persistence
save 900 1              # snapshot if 1 key changed in 900s
appendonly yes          # enable AOF logging

# Logging
loglevel notice
logfile /var/log/redis/redis-server.log

Connecting from Node.js

npm install ioredis

// connect.js
import Redis from 'ioredis';

const redis = new Redis({
  host: '127.0.0.1',
  port: 6379,
  // password: 'yourpassword',  // if set
});

redis.on('connect', () => console.log('Redis connected'));
redis.on('error', (err) => console.error('Redis error:', err));

// Basic usage
await redis.set('hello', 'world');
const val = await redis.get('hello');
console.log(val); // 'world'
ioredis vs node-redis:

ioredis is recommended for production — better cluster support, automatic reconnection, and Lua scripting. node-redis is the official client and also widely used.

Redis Insight (GUI)

Redis Insight is the official free GUI for Redis. It lets you browse keys, run commands, analyze memory, and monitor slow queries.

  1. Download from redis.io/redis-insight
  2. Connect to 127.0.0.1:6379
  3. Browse keys, explore data types, run CLI commands
