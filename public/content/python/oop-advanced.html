Private Attributes & Methods

Prefix a name with two underscores (__) to make it private — accessible only from inside the class.

class Account:
    def __init__(self, account_no, password):
        self.account_no = account_no       # public
        self.__password = password          # private

acc1 = Account(12345, 'abc123')
print(acc1.account_no)      # ✅ 12345
print(acc1.__password)      # ❌ AttributeError
Watch out: Python implements privacy via "name mangling" (_ClassName__attr) — a strong convention, not a hard lock like Java/C++.

Inheritance

A child class derives all properties and methods of a parent class — promoting code reuse.

class Car:                       # Parent / Base / Super class
    color = 'Black'

    @staticmethod
    def start():
        print('Car Started!')

class ToyotaCar(Car):             # Child / Derived / Sub class
    def __init__(self, brand):
        self.brand = brand

car1 = ToyotaCar('Fortuner')
car1.start()        # Car Started! (inherited)
print(car1.color)     # Black (inherited)
print(car1.brand)      # Fortuner (own attribute)

super()

When a child class defines its own __init__, it overrides the parent's. super() explicitly calls the parent's constructor (or any method) so its setup still runs.

class Car:
    def __init__(self, fuel_type):
        self.fuel_type = fuel_type

class ElectricCar(Car):
    def __init__(self, car_type):
        super().__init__('Electric')   # run Car's __init__ first
        self.car_type = car_type        # then set own attribute

car1 = ElectricCar('Prius')
print(car1.fuel_type, car1.car_type)    # Electric Prius
Tip: Always call super().__init__() at the start of the child's __init__ — parent setup first, then child setup.

Three Types of Methods

class Person:
    name = 'Anonymous'        # class attribute

    @classmethod
    def change_name(cls, new_name):
        cls.name = new_name    # modifies the CLASS attribute directly

Person.change_name('Rahul Kumar')
print(Person.name)              # Rahul Kumar — changed for ALL objects
Watch out: self.name = value inside an instance method creates a new instance attribute — it does NOT change the class attribute. Use cls.name = value in a class method instead.

The @property Decorator

Turns a method into a computed attribute that recalculates fresh every time it's accessed — perfect for values that depend on other data.

class Student:
    def __init__(self, physics, chemistry, maths):
        self.physics, self.chemistry, self.maths = physics, chemistry, maths

    @property
    def percentage(self):
        return (self.physics + self.chemistry + self.maths) / 3

s1 = Student(98, 97, 99)
print(s1.percentage)    # 98.0 — accessed like an attribute, no parentheses!

s1.physics = 86
print(s1.percentage)    # 94.0 — automatically recalculated!

Polymorphism & Operator Overloading

Polymorphism means the same operator or method name behaves differently depending on context. The + operator is the most familiar example:

print(1 + 2)               # 3 — arithmetic addition
print('Apna' + 'College')   # ApnaCollege — string concatenation
print([1,2] + [3,4])          # [1, 2, 3, 4] — list merging
# Same operator, three different behaviors!

Dunder (Magic) Functions

Every operator maps to a "dunder" method. a + b internally calls a.__add__(b).

class ComplexNumber:
    def __init__(self, real, imaginary):
        self.real, self.imaginary = real, imaginary

    def __add__(self, num2):              # defines what + means
        return ComplexNumber(self.real + num2.real, self.imaginary + num2.imaginary)

    def show(self):
        print(f'{self.real}i + {self.imaginary}j')

num1, num2 = ComplexNumber(1, 3), ComplexNumber(4, 6)
result = num1 + num2     # calls num1.__add__(num2)
result.show()              # 5i + 9j

Chapter Summary

  • Private members use a double-underscore prefix (__attr) — accessible only inside the class
  • Inheritance lets a child class reuse a parent's attributes and methods: class Child(Parent):
  • Single, multi-level, and multiple inheritance are Python's three inheritance patterns
  • super().__init__() runs the parent's constructor from inside the child's
  • Instance methods use self; class methods use cls; static methods use neither
  • @property turns a method into an auto-recalculating computed attribute
  • Polymorphism means the same operator behaves differently per type — powered by dunder methods like __add__ and __gt__
