Functions & Recursion

A function packages a task so you write it once and reuse it forever — the DRY principle in action. Recursion takes that one step further: a function that solves a problem by calling itself.

Why Functions?

Writing sum = a + b over and over across a codebase is redundant code. A function lets you define the logic once and call it anywhere.

# Define ONCE
def calculate_sum(a, b):
    return a + b

# Call as many times as needed
print(calculate_sum(5, 10))    # 15
print(calculate_sum(2, 10))    # 12
Tip: Rule of thumb — if you write the same 3+ lines of code more than twice, it belongs in a function. This is the DRY principle: Don't Repeat Yourself.

Defining & Calling Functions

def function_name(parameter1, parameter2):

    return value          # optional

def calculate_average(a, b, c):
    return (a + b + c) / 3

avg = calculate_average(98, 97, 95)

Default Parameters

def calculate_product(a, b=1):       # b defaults to 1
    print(a * b)

calculate_product(5)       # a=5, b=1 (default) → 5
calculate_product(5, 3)    # a=5, b=3 (overrides) → 15
Watch out: Non-default parameters must always come before default ones. def func(a=1, b): is a SyntaxError.

What is Recursion?

Recursion is a function calling itself to solve a smaller version of the same problem — until it reaches a stopping point called the base case.

def show(n):
    if n == 0:        # ── BASE CASE ──
        return
    print(n)
    show(n - 1)        # ── RECURSIVE CALL ──

show(5)    # Output: 5  4  3  2  1
Watch out: Recursion without a proper base case runs forever and crashes with RecursionError: maximum recursion depth exceeded. Every recursive function needs one.

The Call Stack

Each recursive call adds a frame to the call stack. When a call hits its base case, it returns and its frame is removed — back up the chain.

def factorial(n):
    if n == 0 or n == 1:    # base case: 0! = 1! = 1
        return 1
    return factorial(n - 1) * n     # n! = (n-1)! × n

print(factorial(5))   # 120
CallComputesReturns
factorial(4)factorial(3) × 4waiting…
factorial(1)base case!1
factorial(2)1 × 22
factorial(3)2 × 36
factorial(4)6 × 424 ← final answer
Note: Code before the recursive call runs on the way down. Code after the recursive call runs on the way back up the call stack.

Writing a Recursive Function — Step by Step

def recursive_function(n):
    # Step 1 — Base Case (stopping condition)
    if n == base_case_value:
        return known_answer

    # Step 2 — Recursive Call with a SMALLER input
    return recursive_function(n - 1)

# Example: sum of first n numbers
def calculate_sum(n):
    if n == 0:
        return 0                          # base case
    return calculate_sum(n - 1) + n      # recursive relation

print(calculate_sum(5))    # 15

Chapter Summary

  • Functions are reusable, named blocks of code — defined with def
  • Parameters and return values are both optional; no return means the function returns None
  • Non-default parameters must come before default parameters in the signature
  • Recursion is a function calling itself — every recursive function needs a base case
  • The call stack holds active calls as layered frames; returning removes a frame
  • Code before the recursive call runs going down; code after runs coming back up
  • Loops and recursion solve the same problems — prefer loops unless the structure is naturally recursive
