Creating Strings

A string stores a sequence of characters. Python gives three ways to create one — each useful when the other quote type appears inside the text.

str1 = "This is a string"        # double quotes — most common
str2 = 'Hello'                    # single quotes
str3 = """Multi-line\nstring"""    # triple quotes — for multi-line text

"It's my college tutorial"        # double quotes when text has an apostrophe
'He said "Hello"'                 # single quotes when text has double quotes
Watch out: Using the same quote type inside and outside the string confuses Python — it thinks the string ended early.

Length, Indexing & Slicing

string = "Apna College"
print(len(string))       # 12 — spaces count too!

# Indexing — always starts at 0; negative counts from the end
print(string[0])         # A
print(string[-1])        # e   (last character)

# Slicing — string[start:end]   (end is EXCLUDED)
print(string[0:4])       # Apna
print(string[5:])        # College   (missing end = go to the end)
print(string[:4])        # Apna      (missing start = from 0)
Strings are immutable: You can read a character with string[0], but string[0] = "B" raises a TypeError. You can never modify a string in place — only create a new one.

String Methods

s = "I am studying Python from Apna College"

s.endswith("ege")        # True
s.capitalize()           # "I am studying python from apna college"
s.replace("Python", "JS")  # "I am studying JS from Apna College"
s.find("o")               # 18 — index of first match, -1 if not found
s.count("o")               # 4  — total occurrences
MethodWhat It DoesExample
upper() / lower()Case conversion"hi".upper() → "HI"
strip()Removes leading/trailing whitespace" hi ".strip() → "hi"
split(sep)Splits into a list"a,b".split(",") → ['a','b']
title()Capitalizes every word"hello world".title()
isdigit() / isalpha()Character-class checks"123".isdigit() → True
Note: String methods never modify the original — they return a new string. Reassign to keep the change: s = s.capitalize().

The if Statement

If the condition is True, the indented block runs. If False, it's skipped entirely.

age = 21
if (age >= 18):
    print("Can vote")
    print("Can apply for licence")
# Output: Can vote
#         Can apply for licence
Indentation is mandatory: Python uses indentation (4 spaces) instead of curly braces { } to define a block. Inconsistent indentation raises an IndentationError.

elif and else

elif ("else if") is checked only when the previous condition was False. else is the catch-all that runs when nothing above matched — and must come last.

light = "yellow"

if (light == "red"):
    print("Stop")
elif (light == "green"):
    print("Go")
elif (light == "yellow"):
    print("Wait / Look")
else:
    print("Light is broken!")
# Output: Wait / Look

Real-World Example — Grading System

marks = int(input("Enter student marks: "))

if (marks >= 90):
    grade = "A"
elif (marks >= 80 and marks < 90):
    grade = "B"
elif (marks >= 70 and marks < 80):
    grade = "C"
else:
    grade = "D"

print("Grade of the student is:", grade)

Nested if & Logical Operators

# Nested if — an if inside another if
age = 95
if (age >= 18):
    if (age >= 80):
        print("Cannot drive — too old")
    else:
        print("Can drive")
else:
    print("Cannot drive — too young")

# Logical operators combine multiple checks in one condition
num = 15
if (num >= 10 and num <= 20):
    print("In range")
Tip: Use and to check a value falls within a range (marks >= 80 and marks < 90) — one of the most common real-world patterns with conditionals.

Chapter Summary

  • Strings are sequences of characters — created with single, double, or triple quotes
  • Indexing starts at 0; negative indexing counts back from -1
  • Slicing [start:end] excludes the end index; strings are immutable
  • String methods (replace, find, count, upper, strip …) return new strings
  • if always runs first; elif only checks when prior conditions were False
  • else has no condition and must be the last block in the chain
  • Indentation (4 spaces) defines code blocks — Python has no curly braces
  • Logical operators (and, or, not) combine multiple conditions in one if
