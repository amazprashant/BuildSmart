What is a List?

A List stores a collection of values in a single variable, created with square brackets [ ].

marks = [94.4, 87.0, 95.0, 66.4, 45.1]      # all floats
student = ["Karan", 95, "Delhi", 3.9]        # mixed types in ONE list
empty = []

print(type(marks))    #
🔢

Ordered

Elements keep the order they were inserted in.

✏️

Mutable

Elements can be changed, added, or removed after creation.

🧬

Mixed Types

Unlike C++/Java arrays, one list can hold int, str, float, bool together.

📈

Dynamic Size

Grows or shrinks as elements are added or removed.

Indexing & Slicing

marks = [85, 94, 76, 63, 48]
#   index:  0   1   2   3   4
#  neg-idx: -5  -4  -3  -2  -1

print(marks[0])      # 85 — first element
print(marks[-1])     # 48 — last element
print(marks[1:4])     # [94, 76, 63] — end is excluded
print(marks[:3])      # [85, 94, 76]
print(marks[:])       # full copy of the list

List Methods

Watch out: Most list methods (append, sort, reverse, insert, remove, pop) return None — they mutate the original list in place. result = mylist.sort() leaves result as None! 
lst = [2, 1, 3]
lst.append(4)          # [2, 1, 3, 4]        — add to end
lst.insert(1, 5)        # [2, 5, 1, 3, 4]      — add at index
lst.remove(1)            # removes first 1 found
last = lst.pop()         # removes & RETURNS last element
lst.sort()                # ascending in place
lst.sort(reverse=True)    # descending in place
lst.reverse()              # flips current order
copy = lst.copy()          # independent shallow copy
lst.count(2)                 # counts occurrences
MethodWhat It DoesReturns

insert(i, x)Add x at index iNone

pop(i)Remove & return element at i (default: last)Removed element

Palindrome check trick: Copy the list, reverse the copy, and compare to the original. If they're equal, it's a palindrome.

What is a Tuple?

A Tuple is List's immutable cousin — created with parentheses ( ). Once created, its values can never change.

tup = (1, 2, 3, 4)
single = (1,)            # ✅ trailing comma REQUIRED for a single-element tuple
not_a_tuple = (1)        # ❌ this is just an int, not a tuple!
coords = 10, 20, 30       # tuples can also be written without parentheses

tup[0] = 99               # ❌ TypeError — tuples are immutable
Watch out: A single-element tuple needs a trailing comma: (1,) not (1). Without it, Python just sees a parenthesized value.

Tuple Methods — Only Two!

tup = (10, 20, 30, 20, 40)
tup.index(20)    # 1 — index of FIRST occurrence
tup.count(20)    # 2 — total occurrences

Key rule: List = mutable, use for changing data. Tuple = immutable, use for fixed data like coordinates, RGB colors, or database records — and it's slightly faster too.

Chapter Summary

  • Lists are ordered and mutable — created with square brackets [ ]
  • Python lists hold mixed data types, unlike arrays in C++/Java
  • Most list methods mutate in place and return None — don't reassign the result
  • pop(i) deletes by index and returns the removed element; remove(x) deletes by value
  • Tuples are ordered and immutable — created with parentheses ( )
  • A single-element tuple needs a trailing comma: (1,)
  • Tuples have only two methods: index() and count()
  • Use lists for changing collections, tuples for fixed/constant data
