Loops in Python

Loops let you repeat a task without copy-pasting code 100 times. Python gives you two flavors — while for condition-based repetition, and for for iterating over a sequence.

Why Loops?

Printing "Hello" 5 times manually doesn't scale to 100,000 times. A loop solves it in 3 lines, however many repetitions are needed.

# Without a loop — does not scale
print("Hello"); print("Hello"); print("Hello")

# With a loop — works for 5 or 100,000 repetitions
i = 1
while i <= 5:
    print("Hello")
    i += 1

The while Loop

Keeps running as long as its condition is True. The moment it becomes False, the loop stops.

i = 1                   # 1. Initialization
while i <= 5:           # 2. Condition check
    print(i)              # 3. Task
    i += 1                  # 4. Update
# Output: 1  2  3  4  5

# Counting down
i = 5
while i >= 1:
    print(i)
    i -= 1
Infinite loop danger: If the condition never becomes False, the loop never stops and crashes your program. Always make sure the iterator moves toward the stopping condition.

Traversing a List/Tuple with while

nums = [1, 4, 9, 16, 25]
index = 0
while index < len(nums):
    print(nums[index])
    index += 1

break and continue

KeywordEffectLoop Continues?
breakExits the entire loop immediatelyNo
continueSkips the rest of the current iterationYes — next iteration begins
# break — stop searching once found
nums = (1, 4, 9, 16, 25, 36)
i = 0
while i < len(nums):
    if nums[i] == 36:
        print('Found at index', i)
        break          # stop immediately, no further checking
    i += 1

# continue — skip even numbers, print only odd
i = 1
while i <= 10:
    if i % 2 == 0:
        i += 1
        continue       # jump back to condition check
    print(i)
    i += 1
# Output: 1  3  5  7  9
Watch out: With continue in a while loop, update the iterator before the continue — otherwise you create an infinite loop.

The for Loop

A for loop iterates over a sequence automatically — no manual index tracking needed.

numbers = [1, 2, 3, 4, 5]
for value in numbers:
    print(value)

for char in "Apna College":     # works on strings too
    print(char)

for num in (10, 20, 30):          # and tuples
    print(num)

Optional else with Loops

The else block runs only if the loop finishes without hitting a break.

for char in "Apna College":
    if char == 'z':
        print("Found z!")
        break
else:
    print("z not found")     # runs — no break occurred
# Output: z not found

The range() Function

for i in range(1, 101):       # 1 to 100 — stop is exclusive, so 101 is needed
    print(i)

for i in range(100, 0, -1):     # counting down
    print(i)

for i in range(2, 11, 2):         # even numbers
    print(i)
Watch out: The stop value in range() is always exclusive. range(5) gives 0-4, never 5.

The pass Statement

pass does nothing — it's a placeholder when Python requires a statement but you don't want any action yet.

for i in range(5):
    pass    # TODO: add logic here later
print("After loop")   # works fine — no IndentationError

Nested Loops & Linear Search

# Nested loop — inner loop completes fully for EACH outer iteration
for i in range(1, 4):
    for j in range(1, 4):
        print(i, j)
# Total: 3 × 3 = 9 lines printed

# Linear Search — check each element one by one
nums = (1, 4, 9, 16, 25, 36, 49)
x = 36
for index, num in enumerate(nums):
    if num == x:
        print('Found at index', index)
        break
Tip: Sum of n numbers: accumulate with sum += i. Factorial: accumulate with factorial *= i — but start factorial at 1, never 0!

Chapter Summary

  • while repeats as long as a condition stays True — manual init/condition/update
  • for automatically iterates over lists, tuples, strings, dicts, sets, and range()
  • break exits the entire loop; continue skips only the current iteration
  • range(stop), range(start, stop), and range(start, stop, step) — stop is always exclusive
  • pass is a null statement used as a placeholder for empty blocks
  • Nested loops: the inner loop fully completes for every single outer iteration
  • Linear Search checks each element one by one until a match or the list ends
