Dictionary & Set

A dictionary maps keys to values, just like a real dictionary maps words to meanings. A set stores only unique values with no particular order. Both are essential, everyday Python data structures.

What is a Dictionary?

A Dictionary stores a collection of key-value pairs, created with curly braces { }. You look up a key to find its value — just like looking up a word to find its meaning.

info = {
    "name": "Apna College",
    "age": 35,
    "is_adult": True
}

print(type(info))    # 
empty = {}            # empty dictionary
PropertyDescription
UnorderedNo index numbers like lists — accessed by key, not position
MutableValues can change; pairs can be added or removed
No duplicate keysAdding the same key again overwrites the old value
Key restrictionsKeys must be immutable: str, int, float, bool, tuple — never list or dict

Accessing & Modifying Values

info = {"name": "Apna College", "age": 35}

print(info["name"])         # Apna College
print(info["surname"])      # ❌ KeyError — key doesn't exist!

print(info.get("name"))      # Apna College
print(info.get("surname"))   # None — no error!
print(info.get("city", "Unknown"))  # default value if missing

info["city"] = "Delhi"       # add a new key
info["name"] = "New Name"    # update an existing key
Watch out: dict[key] raises a KeyError and stops your program if the key is missing. Use dict.get(key) in real-world code — it returns None instead of crashing.

Nested Dictionaries

student = {
    "name": "Rahul Kumar",
    "subjects": {                # value is itself a dictionary
        "Physics": 85,
        "Chemistry": 90
    }
}

print(student["subjects"]["Chemistry"])   # 90 — double brackets go one level deeper

Dictionary Methods

info = {"name": "Rahul", "age": 25}

info.keys()                  # dict_keys(['name', 'age'])
info.values()                 # dict_values(['Rahul', 25])
info.items()                   # dict_items([('name','Rahul'), ('age',25)])
info.update({"city": "Delhi"})  # add/update multiple pairs at once
info.pop("age")                  # remove & return value for key
MethodWhat It Does
.keys() / .values() / .items()View all keys / values / key-value pairs
.get(key, default)Safe access — returns default instead of crashing
.update(dict2)Merge another dictionary in — updates existing, adds new
.pop(key)Remove a key and return its value

What is a Set?

A Set stores a collection of unique, unordered values — duplicates are automatically ignored.

nums = {1, 2, 2, 3, 3, 3, 4}
print(nums)            # {1, 2, 3, 4} — duplicates removed!

empty_set = set()       # ✅ correct way to make an empty set
empty_dict = {}          # ❌ this is a DICTIONARY, not a set!
Watch out: Sets and dictionaries both use { }. An empty {} always creates a dictionary — use set() for an empty set.

Elements Must Be Immutable

s = {1, 2, 3}
s.add('hello')        # ✅ string — immutable, allowed
s.add((1, 2))           # ✅ tuple — immutable, allowed
s.add([1, 2])             # ❌ TypeError: unhashable type: 'list'

Set Methods & Operations

nums = {1, 2, 3}
nums.add(4)                  # {1, 2, 3, 4}
nums.remove(3)                # {1, 2, 4} — KeyError if missing
nums.discard(99)               # no error even if missing

set1 = {1, 2, 3}
set2 = {2, 3, 4}
set1.union(set2)               # {1, 2, 3, 4} — all unique elements
set1.intersection(set2)         # {2, 3} — common elements only
set1.difference(set2)            # {1} — in set1 but not set2
Tip: Need the count of unique items in a collection? Convert it to a set and call len() — duplicates are handled for you automatically.

Chapter Summary

  • Dictionaries store key-value pairs; keys must be unique and immutable
  • Use dict.get(key) over dict[key] when a key might be missing
  • Nested dictionaries are accessed with chained brackets: dict[k1][k2]
  • Adding a duplicate key overwrites the old value — never creates a duplicate
  • Sets store unique, unordered values — duplicates are silently ignored
  • An empty set must use set(), never {} (that's a dict)
  • Set elements must be immutable; the set itself is mutable
  • union(), intersection(), and difference() combine sets mathematically
