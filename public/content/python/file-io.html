File Input/Output

Variables live in RAM and vanish when your program ends. To persist data permanently, you read from and write to files on disk — Python makes this simple with open().

RAM vs Persistent Storage

Storage TypeSpeedPersistent?Used For
RAMFastNo — lost on shutdownRunning programs, variables
SSD / HDD (Files)SlowerYes — persists foreverPhotos, code, documents, logs

File I/O — Open, Read, Write, Append, Close, Delete — is how Python moves data between RAM and permanent disk storage.

Opening a File & Modes

f = open('demo.txt', 'r')      # default mode: read
f = open('demo.txt')            # same as above
ModeDescriptionCreates if Missing?
'r'Read only (default)No → FileNotFoundError
'w'Write — TRUNCATES existing content firstYes
'a'Append — preserves existing contentYes
'x'Create — fails if file already existsYes
Watch out: 'w' mode permanently erases existing content before writing. Use 'a' if you want to add data without deleting what's already there.

Reading from a File

f = open('demo.txt', 'r')
data = f.read()        # entire file as ONE string
print(data)
f.close()

f = open('demo.txt', 'r')
line = f.readline()      # one line at a time; '' when file ends
f.close()

f = open('demo.txt', 'r')
lines = f.readlines()      # list of all lines, each ending in '\n'
f.close()
MethodReturnsBest For
read()All content as one stringSmall files, need everything
readline()One line at a timeProcessing line by line
readlines()List of all linesNeed all lines as a list

Writing to a File

# 'w' — overwrite everything
f = open('demo.txt', 'w')
f.write('Line 1: Hello World\n')
f.write('Line 2: Learning Python\n')
f.close()

# 'a' — append without deleting existing data
f = open('demo.txt', 'a')
f.write('\nLine 3 appended')
f.close()
Note: write() never adds a newline automatically — include \n yourself if you want a new line.

The with Statement — Preferred Way

with auto-closes the file when the block ends — no manual close(), and cleanup still happens even if an error occurs.

with open('demo.txt', 'r') as f:
    data = f.read()
    print(data)
# file is automatically closed here

with open('demo.txt', 'w') as f:
    f.write('New content here')
Tip: Always use with open(...) as f: in real Python code — it's the safer, industry-standard pattern.

Deleting Files — the os Module

File methods alone can't delete a file — import the built-in os module.

import os

filename = 'sample.txt'
if os.path.exists(filename):
    os.remove(filename)
    print("File deleted successfully")
else:
    print("File not found")
Watch out: os.remove() deletes permanently — there's no recycle bin or undo.

Common Pattern — Modify File Content

You can't edit a file in place. Always: READ into a string → MODIFY the string in memory → WRITE it back.

def replace_word(filename, old_word, new_word):
    with open(filename, 'r') as f:
        data = f.read()

    new_data = data.replace(old_word, new_word)

    with open(filename, 'w') as f:
        f.write(new_data)

replace_word('practice.txt', 'Java', 'Python')

Chapter Summary

  • RAM is temporary; files on disk persist data across program runs and restarts
  • open(filename, mode) opens a file — default mode is 'r'
  • 'w' erases existing content first; 'a' preserves it and appends
  • read(), readline(), and readlines() each read content differently
  • Always prefer with open(...) as f: — it auto-closes the file safely
  • Deleting requires the built-in os module: os.remove(filename)
  • To modify a file: read into a string, modify the string, write it back
