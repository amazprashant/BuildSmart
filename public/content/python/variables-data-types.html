What is Programming?

Programming means giving instructions to a machine using code. We write these instructions in a programming language so the machine can understand and execute them — just like we'd speak French in France to communicate.

Why Python needs a translator: Computers only understand binary (0s and 1s). Python is a high-level language close to English. An Interpreter translates Python code into machine language, line by line, at runtime.
TermMeaning
High-Level LanguageEasy for humans to read (Python, Java, JavaScript)
Low-Level / Machine LanguageBinary (0s and 1s) understood directly by hardware
InterpreterTranslates code line-by-line at runtime — what Python uses
CompilerTranslates the entire program at once, before running

Your First Program — print()

The print() function displays output on the screen.

print("Hello, World!")
print(23)                       # numbers print directly
print(35 + 23)                  # 58

# Multiple values on one line, separated by a comma
print("Name:", "Shradha")       # Output: Name: Shradha
print("Age:", 23)                # Output: Age: 23
Note: A comma inside print() separates values with a space but keeps them on the same line. Use separate print() calls for new lines.

Variables

A variable is a name given to a memory location that stores data which can be used and changed later — just like Area = a × b in math, where a and b can vary.

name = "Shradha"     # String variable
age = 23              # Integer variable
price = 25.99         # Float variable

print(name)           # Shradha — fetches the variable's value
print("name")         # name    — literal text, NOT the variable

Naming Rules

  • Can contain letters, digits, and underscore (_) — cannot start with a digit
  • Cannot use special symbols (% @ # $ !) or Python keywords
  • Python is case-sensitive — apple and Apple are different variables
Assignment ≠ Equality: In Python, = means assignment — the value on the right is stored into the variable on the left. Use == to check equality.

Comparison, Assignment & Logical

# Comparison — always returns True/False
a, b = 50, 20
print(a == b, a != b, a > b, a <= b)   # False True True False

# Assignment shorthand
num = 10
num += 5     # same as: num = num + 5

# Logical
print(True and False)   # False
print(True or False)    # True
print(not True)          # False
Watch out: Division (/) always returns a float in Python — 4 / 2 is 2.0, not 2.

Type Conversion

Implicit conversion happens automatically (Python promotes int → float to avoid data loss). Explicit conversion (type casting) is done manually.

a = 2          # int
b = 4.25       # float
print(a + b)   # 6.25 — 'a' auto-converted to 2.0

a = "2"
b = 4.25
print(int(a) + b)   # 6.25 — manual cast required for strings

int("25")     # 25
float("3.14") # 3.14
str(100)      # "100"
bool(0)       # False

Taking Input

input() pauses the program and waits for the user — and it always returns a string, no matter what was typed.

name = input("Enter your name: ")
age = int(input("Enter your age: "))        # cast to int
marks = float(input("Enter your marks: "))  # cast to float

print("Welcome", name)
print("Your age is:", age)

Chapter Summary

  • Python uses an Interpreter to translate code to machine language
  • Variables are declared as variable_name = value — no type keyword needed
  • Python has 5 primary data types: int, float, str, bool, NoneType
  • Python is case-sensitive: True ≠ true, name ≠ Name
  • 4 operator families: Arithmetic, Comparison, Assignment, Logical
  • Type Conversion is Implicit (automatic) or Explicit (manual casting)
  • input() always returns a string — cast it to use as a number
