Section 02

Two Ways to Connect MCP Servers to Claude Desktop

There are exactly two methods to connect any MCP server to Claude Desktop (or any AI host). Understanding the difference between these two is fundamental to this entire video.

Method 1 — Connectors (One-Click)

What: Built-in feature in Claude Desktop. Click a button and connect instantly.
For whom: Non-technical users; anyone using popular SaaS tools.
Setup: Zero configuration. No JSON file editing. Authentication handled automatically.
Available for: Curated popular tools — Google Drive, Gmail, Calendar, Notion, Slack, Asana, HubSpot, Indeed, Hugging Face, and more.
Maintained by: Anthropic team writes, hosts, and maintains all connector code.
Analogy: Like an App Store for MCP servers.

Method 2 — JSON Config File (Manual)

What: Edit a JSON configuration file that Claude Desktop reads on startup.
For whom: Developers; anyone with a custom/personal MCP server.
Setup: Requires: Settings → Developer → Edit Config → Edit JSON → Restart Claude.
Available for: Any MCP server — custom-built, community, enterprise-specific, or personal.
Maintained by: You. You manage the config, paths, API keys, and updates.
Analogy: Like adding a custom app manually rather than from a store.
Key insight: Both methods achieve the same result — an MCP server is added to the mcpServers JSON object that Claude Desktop reads. Connectors just automate the JSON editing for you behind the scenes.
Section 03

Connectors — What They Are & Why They Exist

Definition: A Connector is a built-in feature that links Claude to MCP servers automatically, without the need for manual setup and configuration. Click a button → connected.

The Problem Connectors Solve

Most Claude Desktop users are non-technical. They want to connect Claude to Google Drive or Notion — but the manual JSON config approach requires: finding the GitHub repo, reading setup docs, editing JSON files, managing API keys, debugging errors. That's too technical for everyday users.

🛡️

Safer

All connector code is written and reviewed by Anthropic's team. OAuth flows, API key handling, and authentication are battle-tested and secure. No risk of misconfiguring sensitive credentials.

⚡

Easier

Click "Add Connectors" → select a service → sign in → done. No terminal, no JSON, no paths to configure. A non-technical person can add an MCP server in under 30 seconds.

🎯

More Consistent

Manual JSON config often fails to load on first try due to path errors, missing dependencies, or syntax mistakes. Connectors have a near-100% success rate because Anthropic controls the entire setup flow.

Section 04

Why Not Force All MCP Servers to Use Connectors?

If connectors are safer, easier, and more consistent — why not require all MCP servers to use them? Two fundamental reasons prevent this:

🏗️

Reason 1 — Not Scalable

Connectors require Anthropic's team to manually write, host, and maintain every connector. There are thousands of MCP servers — with 10–15 new ones created every day. It's physically impossible for one company to build and maintain connectors for every MCP server in existence.


Anthropic writes the entire connector code, handles OAuth flows, manages security patches, rate limiting, and ensures a stable experience. This is enormous ongoing work.

🔓

Reason 2 — MCP is an Open Standard

MCP was designed so anyone can build a client or server. If connectors were mandatory, a developer would have to: build an MCP server → submit it to Anthropic → wait for review → wait for Anthropic to build a connector → only then connect it to Claude Desktop.


This closes the open ecosystem and gives Anthropic a gatekeeper role — contrary to MCP's founding principles. The JSON config approach preserves openness.

Installing Claude Desktop

🍎

macOS

Go to claude.ai/download → Download the macOS version → Open the .dmg file → Drag to Applications → Launch → Sign in with your Claude/Anthropic account.

🪟

Windows

Go to claude.ai/download → Download the Windows version → Run the installer → Follow installation wizard → Launch → Sign in with your Claude/Anthropic account.

Critical rule — Always restart after adding MCP servers: Every time you add a new MCP server (via connector or JSON config), you MUST close and relaunch Claude Desktop for it to take effect. Claude reads the MCP server config only at startup.

Where is the JSON Config File?

Navigate to: Claude Desktop → Settings → Developer → Edit Config. This opens the claude_desktop_config.json file in your default editor. The file contains the mcpServers object where all server configurations live.

// claude_desktop_config.json — the master config file
{
  "mcpServers": {
    // Each key is the server name, value is its config
    "filesystem": { ... connector auto-adds this ... },
    "manim": { ... manually added ... },
    "twitter": { ... manually added ... },
    "weather": { ... manually added ... }
  }
}

Server 1 — Filesystem MCP
Local Server · Connected via Connector · Read + Write
Connector

The Filesystem MCP server gives Claude access to specified directories on your local machine. It can list files, read file contents, create new files, and edit existing ones.

Setup Steps

01
Click the Search & Tools icon in Claude Desktop

This is the icon at the bottom of the chat input bar. A panel opens showing connected tools.

02
Click "Add Connectors" → Desktop Extensions → Filesystem

Browse the connector library and find the Filesystem connector. Click to install it.

03
Configure allowed directories

After installing, you must specify which folders on your machine the server can access. Example: add your Desktop folder. This is a safety feature — the server cannot access any path outside what you specify.

04
Enable the connector and restart Claude Desktop

Toggle it to Enabled → Close Claude Desktop → Reopen. The Filesystem server is now connected.

Demo Results

Read Files Demo

Query: "Are there any PDF files on my Desktop?"

Result: Claude used the list_directory and search_files tools, scanned the Desktop, and returned a list of 5 PDF files found.

Write Files Demo

Query: "Write a Fibonacci numbers code in Python, then save the first version as a .py file on my Desktop."

Result: Claude generated 3 versions of Fibonacci code, then used the write_file tool to create and save fibonacci.py directly on the Desktop.

Creative Use Cases

Organize Downloads Folder

Point Filesystem at your chaotic Downloads folder and ask Claude to organize everything into logical subfolders by file type, date, or project.

Summarize Code Projects

Add your project directory and ask Claude to give you a quick summary of what the codebase does, what files exist, and how it's structured.

Bulk File Operations

Rename hundreds of files following a pattern, convert file formats, extract data from multiple files, or create structured reports from file contents.

Safety first: Never give Filesystem access to your entire root directory. Always restrict it to specific folders you're comfortable with Claude reading and modifying. Giving full system access could be dangerous if Claude makes an error.

Server 2 — Manim MCP
Local Server · Connected via JSON Config · Generate math animations
JSON Config

Manim is the Python library used by the famous 3Blue1Brown YouTube channel to create stunning mathematical visualizations. The Manim MCP server lets Claude generate these animations from plain English prompts.

The 3Blue1Brown connection: 3Blue1Brown makes complex math beautiful through animated visualizations. They use Manim to code every visualization manually — a very hard skill. This MCP server removes that barrier: describe what you want in English → get a professional math animation video.

Prerequisites

Python 3.x

Must be installed on your machine. Check with python3 --version in terminal.

Manim Library

Install with: pip install manim

MCP Library

Install with: pip install mcp

Optional — LaTeX: For perfect mathematical symbols (∫, Σ, matrices), install LaTeX (~10–15 GB). Without it, Manim will use fallback rendering — symbols may not look as polished. Recommended to skip LaTeX unless you specifically need perfect symbols.

Setup Steps (JSON Config Method)

01
Clone the Manim MCP Server repository to your Desktop

Search "manim mcp server" on Google, find the GitHub repo. Clone it to your Desktop (important: Claude needs Desktop access from the Filesystem connector).

02
Find Python's absolute path on your machine

In terminal: which python3 (Mac/Linux) or check your Python installation path on Windows. Copy the full path.

03
Find Manim's executable path

In terminal: which manim (Mac/Linux). On Windows, look in your Python Scripts folder.

04
Open Claude Desktop config: Settings → Developer → Edit Config

This opens claude_desktop_config.json. Open it in VS Code or any text editor.

05
Add the Manim server config block inside "mcpServers"

Copy the config template from the Manim GitHub repo README. Paste it inside the mcpServers object. Replace the placeholder paths with your actual Python path, Manim path, and the cloned repo path.

06
Save the file and restart Claude Desktop

Close Claude Desktop completely, reopen it. The Manim server should now appear in your connected tools list.

JSON Config Template

// Add inside "mcpServers" object in claude_desktop_config.json
"manim": {
  "command": "/usr/local/bin/python3",   // Your Python absolute path
  "args": [
    "/Users/yourname/Desktop/manim-mcp-server/src/server.py"
  ],                                            // Path to cloned repo's server.py
  "env": {
    "MANIM_PATH": "/usr/local/bin/manim"   // Your Manim executable path
  }
}
// Windows: paths use backslashes, e.g. C:\Users\yourname\...

Demo: Vector Transformation Animation

// Prompt used to generate the animation
"Use the Manim server to create an animation showing the concept of
Vector Transformation in Linear Algebra. First create a 2D coordinate
grid. Show two basis vectors I and J. Apply this matrix transformation:
[[2, 1], [1, 3]]. Show the entire grid bending according to the matrix.
Show the new transformed vectors. Add the title 'Linear Transformation'."

// What happened:
// 1. Claude generated Manim Python code for this exact animation
// 2. The Manim MCP server executed the code
// 3. A video file was generated showing:
//    - 2D coordinate grid
//    - Original basis vectors i and j
//    - The grid morphing/rotating per the transformation matrix
//    - New vectors i' and j' after transformation
Recommendation: This MCP server has been in use for ~1.5 months. Whenever a difficult concept in ML/DL comes up: (1) ask Claude/ChatGPT to write a Manim prompt for that concept, (2) paste the prompt into Claude Desktop with Manim connected, (3) get a visualization video in minutes. Learning output has improved significantly with this workflow.

Server 3 — Google Drive MCP
Remote Server · Connected via Connector · Read-Only
Connector

The Google Drive MCP server connects Claude Desktop to your Google Drive account, allowing Claude to search and read your documents. This is a remote server — it runs on the internet, not on your machine.

Setup Steps (One-Click Connector)

01
Click Search & Tools icon → Google Drive appears directly in the panel

Google Drive is so popular it gets a direct shortcut in the tools panel — you don't even need to go to "Add Connectors".

02
Click the Drive icon → OAuth authentication flow opens

Your browser opens a Google sign-in page. This is the standard Google OAuth flow — the same process used by any Google-connected app.

03
Sign in to your Google account → Grant permissions

Allow Claude Desktop to read your Google Drive files. Anthropic manages the OAuth flow and ensures your credentials are handled securely.

04
Done — no restart needed for connectors

Once OAuth completes, the Drive Search connector is enabled immediately. You'll see "Drive Search" appear in your connected tools panel.

Demo Result

// Live demo from the video
// Query sent to Claude Desktop:
"Can you summarize the document from my Google Drive called
'AI Newsletter Content Ideas'?"

// What happened:
// 1. Claude used the drive_search tool to search Google Drive
// 2. Found the document "AI Newsletter Content Ideas"
// 3. Read the document content via the Drive API
// 4. Generated a comprehensive summary
// All within seconds, with full context from the Drive document
⚠️ Important limitation — Read-Only: The Google Drive MCP connector is currently read-only. You can search and read existing documents, but you cannot create new files, edit existing files, or delete anything. It's purely for pulling context from your Drive into Claude's conversation.

Server 4 — Twitter/X MCP
Local Server (npm) · JSON Config · Search + Post tweets
JSON Config

The Twitter/X MCP server lets Claude read and post tweets. It runs locally on your machine (installed via npm behind the scenes) and connects to the Twitter API using your developer credentials.

Correction noted: Initially planned as a "remote" server, but discovered mid-video that it's actually a local server — the JSON config runs an npx command which installs and runs the server locally via npm. This is an important architectural detail.

Prerequisites

Node.js + npm

The Twitter MCP server uses npx, which requires Node.js. Install from nodejs.org. Verify with node --version and npm --version.

Twitter Developer Account + 4 API Keys

Go to developer.twitter.com → create/use a project → get: API Key, API Secret, Access Token, Access Token Secret. All 4 required.

Setup Steps

01
Create a Twitter Developer Account

Go to developer.twitter.com → sign in with your Twitter/X account → access the Developer Dashboard → use the Default Project.

02
Get your 4 API keys from the Developer Portal

In your project → Keys and Tokens → Regenerate API Key & Secret → Generate Access Token & Secret. Copy all 4 values.

03
Open Claude config and add the Twitter server block

Settings → Developer → Edit Config → add the Twitter config block inside mcpServers.

04
Paste your 4 API keys into the config

Replace the placeholder values with your actual API Key, API Secret, Access Token, and Access Token Secret.

05
For write (posting) permissions: update app settings in Dev Portal

By default, Twitter apps may only have read permissions. Go to Developer Portal → Your App → User Authentication Settings → enable Read and Write permissions.

06
Save config, restart Claude Desktop

After restart, Twitter MCP server appears with 2 tools: post_tweet and search_tweets.

JSON Config Template

"twitter": {
  "command": "npx",    // Uses npm package executor — installs locally
  "args": ["-y", "@some-package/twitter-mcp-server"],
  "env": {
    "TWITTER_API_KEY":            "your_api_key_here",
    "TWITTER_API_SECRET":         "your_api_secret_here",
    "TWITTER_ACCESS_TOKEN":       "your_access_token_here",
    "TWITTER_ACCESS_TOKEN_SECRET":"your_access_token_secret_here"
  }
}
// Note: npx installs the package locally on first run
// This is a LOCAL server despite using internet-hosted npm package

Available Tools

🔍 search_tweets

Search Twitter for tweets by keyword, hashtag, or topic. Returns recent matching tweets. Working in demo.

📝 post_tweet

Post a new tweet on your behalf. Requires Read+Write permissions in the Developer Portal. Auth issue in demo — needs permissions fix.

Server 5 — Weather MCP (AccuWeather)
True Remote Server · JSON Config · Real-time weather data
Remote

The Weather MCP server is a true remote server — the server code runs remotely (on a GitHub-hosted location), not on your local machine. It provides real-time weather data via the AccuWeather API.

Why this is a true remote server: The JSON config uses uvx to run a server from a GitHub URL directly. The server code is not cloned to your machine — it's fetched and run from the remote source each time. This is the key difference from the Manim server (which you clone locally) and the Twitter server (which npm installs locally).

Prerequisites

uv / uvx Tool

A fast Python package runner. Install with: pip install uv. Get the absolute path with which uvx (Mac/Linux) for the JSON config.

AccuWeather API Key

Sign up at developer.accuweather.com. Free tier is available (~15-day trial with full access, then limited free calls per day). Get your API key from the dashboard.

JSON Config Template

"weather": {
  "command": "/Users/yourname/.local/bin/uvx",  // Absolute path to uvx
  "args": [
    "--from",
    "git+https://github.com/someone/weather-mcp-server",  // Remote GitHub repo
    "weather-mcp-server"  // Package name — runs remotely!
  ],
  "env": {
    "ACCUWEATHER_API_KEY": "your_accuweather_api_key_here"
  }
}
// Key insight: the GitHub URL means server code stays remote — not downloaded locally
// uvx fetches and runs it each time — this IS a true remote server pattern
Demo note: The weather server encountered an API error during the live demo. Try it yourself — if it doesn't work, a different working weather MCP server will be covered in a future video. The setup process shown is correct even if the demo had issues.

JSON Config File — Complete Reference

Here is the complete claude_desktop_config.json after adding all 4 servers (plus what connectors add automatically).

// Full claude_desktop_config.json with all servers connected
{
  "mcpServers": {

    // ── CONNECTOR-ADDED (auto-managed, don't edit manually) ──
    "filesystem": {
      // Added automatically by the Filesystem Connector
      // Connector manages this entry — you only configure allowed directories in the UI
    },
    "drive-search": {
      // Added automatically by the Google Drive Connector
      // OAuth tokens managed by Anthropic's connector system
    },

    // ── MANUALLY ADDED (JSON config method) ──
    "manim": {
      "command": "/usr/local/bin/python3",
      "args": ["/home/user/Desktop/manim-mcp-server/src/server.py"],
      "env": {
        "MANIM_PATH": "/usr/local/bin/manim"
      }
    },

    "twitter": {
      "command": "npx",
      "args": ["-y", "@anthropic-mcp/twitter-server"],
      "env": {
        "TWITTER_API_KEY":            "YOUR_KEY_HERE",
        "TWITTER_API_SECRET":         "YOUR_SECRET_HERE",
        "TWITTER_ACCESS_TOKEN":       "YOUR_TOKEN_HERE",
        "TWITTER_ACCESS_TOKEN_SECRET":"YOUR_TOKEN_SECRET_HERE"
      }
    },

    "weather": {
      "command": "/usr/local/bin/uvx",
      "args": [
        "--from",
        "git+https://github.com/user/weather-mcp-server",
        "weather-mcp-server"
      ],
      "env": {
        "ACCUWEATHER_API_KEY": "YOUR_ACCUWEATHER_KEY_HERE"
      }
    }

  }
}

JSON Config Fields Explained

FieldTypeMeaningExample
commandStringThe executable that runs the MCP server. Use ABSOLUTE paths — relative paths often fail./usr/local/bin/python3, npx, /path/to/uvx
argsArrayCommand-line arguments passed to the command. For local servers: path to the server script. For npm servers: package name.["/path/to/server.py"], ["-y", "package-name"]
envObjectEnvironment variables passed to the server process. Used for API keys, secrets, configuration values.{"API_KEY": "abc123"}
Critical tip — Use absolute paths: Always use full absolute paths (not python3 but /usr/local/bin/python3). Claude Desktop may not have the same PATH environment as your terminal, so relative commands or just executable names often fail to launch the server.

Key Takeaways & What's Next

// Summary: The 4 combinations you now know

Core Things You Learned

🔌 Two Connection Methods

Connectors (one-click, for popular SaaS tools, managed by Anthropic) and JSON Config (manual editing, for any custom server, managed by you). Both add servers to the same mcpServers JSON object.

💻 Local vs Remote Servers

Local: runs on your machine (Filesystem, Manim, Twitter via npm). Remote: runs elsewhere — Google Drive (cloud), Weather (remote GitHub repo via uvx). Transport differs: local uses stdio, remote uses HTTP+SSE.

🔄 Always Restart After Adding

Every time you add or edit an MCP server configuration (via JSON), close and relaunch Claude Desktop. Config is only read on startup.

🛡️ Security Best Practices

Restrict Filesystem to specific directories. Never give Claude access to your root. Store API keys in the env field of JSON config — not hardcoded in prompts. Delete/rotate API keys after demo videos.
